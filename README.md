# Gonzalez_ModularCalculator

# Description
A program that lets the user choose and operation, and perform the operation with different inputs.

# How to run
1. Open program file
2. Run program
3. Choose operation
4. Input values
5. See output

# Inputs needed
- choice
- num1
- num2

# Sample output
Choose a process
1. Addition (+)
2. Subtraction (-)
3. Multiplication (*)
4. Division (/)
Which operation will you choose?(1-4):2
Insert first number:8
Insert second number:7
Result is: 1.0

# Changes from V1 to V2
- V1
Initial Modular Calculator
- V2
1. Simplified function operations removing the use for variables.
